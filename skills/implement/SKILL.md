Implement the work described by the user in the spec or tickets.

Read and follow the sibling `tdd` skill at `../tdd/SKILL.md` where possible, using pre-agreed seams.

Run typechecking regularly, single test files regularly, and the full test suite once at the end.

Once done, read and follow the sibling `code-review` skill at `../code-review/SKILL.md` to review the work.

Do not commit the work unless the user explicitly asks for a commit. Before any Git action, including read-only inspection, tell the user what you are about to run.
